# Changelog

Todos los cambios importantes de este proyecto serán documentados en este archivo.

Este proyecto sigue un versionado semántico (Semantic Versioning).

---

## [1.0.0] - 2026-07-30

### Added
- Creación del proyecto BingoBeat.
- Sistema de cartones aleatorios.
- Modo Jugador.
- Modo Anfitrión.
- Persistencia del cartón mediante LocalStorage.
- Aplicación instalable como PWA.
- Manifest configurado.
- Diseño responsive para computadoras y dispositivos móviles.

### Changed
- Cambio de nombre de "Bingo Musical 90s" a "BingoBeat".
- Mejoras en el diseño responsive.
- Corrección del botón "¡Bingo!" para evitar superposición con el tablero.
- Mejor organización visual del tablero.

### Fixed
- Corrección de problemas de visualización en dispositivos móviles.
- Corrección de la desaparición del texto al marcar casillas.
