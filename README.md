# BingoBeat 🎵

BingoBeat es una aplicación web de bingo musical...

## Características

- 🎵 Cartones aleatorios.
- 📱 Compatible con celulares, tablets y computadoras.
- 💾 Guarda el cartón del jugador.
- 🎤 Modo Anfitrión.
- 🙋 Modo Jugador.
- 🎉 Verificación de Bingo.
- 🚀 Instalable como PWA.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- LocalStorage
- PWA (Manifest)

## Aviso legal

Esta aplicación:

- No almacena archivos de audio.
- No distribuye música.
- No reproduce canciones.
- Utiliza únicamente los títulos como referencia para la dinámica del juego.

La reproducción de música es responsabilidad del organizador del evento y debe realizarse mediante servicios autorizados.
