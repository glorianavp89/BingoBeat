BingoBeat 🎵

BingoBeat es una aplicación web de bingo musical diseñada para eventos, fiestas, bares, actividades educativas y reuniones corporativas.

Los participantes reciben un cartón aleatorio y marcan las canciones conforme el anfitrión las reproduce desde cualquier plataforma de música.

Características
🎵 Cartones aleatorios.
📱 Compatible con celulares, tablets y computadoras.
💾 Guarda el cartón del jugador.
🎤 Modo Anfitrión.
🙋 Modo Jugador.
🎉 Verificación de Bingo.
🚀 Instalable como PWA.

Aviso legal

Esta aplicación:

No almacena archivos de audio.
No distribuye música.
No reproduce canciones.
Utiliza únicamente los títulos como referencia para la dinámica del juego.

La reproducción de música es responsabilidad del organizador del evento y debe realizarse mediante servicios autorizados.
